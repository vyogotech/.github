# Vyogo Technologies

We're an open-source software engineering company. Most of what we ship today lands in the
[Frappe](https://frappeframework.com) and [ERPNext](https://erpnext.com) ecosystem — a Kubernetes/OpenShift operator
for running Frappe in production, a package manager for Frappe apps, ready-to-run container images, single-site
multi-tenant foundations for SaaS builds, and MCP-backed conversational interfaces over ERPNext data. That's our focus,
not our boundary: the same work is Go, Python and TypeScript across Kubernetes, developer tooling and applied AI, and
we take on problems well outside this stack. Built in the open, contributions welcome.
